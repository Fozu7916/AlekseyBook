A social network with a modern interface and advanced functionality.

## Features

- 👥 User profiles
- 💬 Real-time chat
- 👋 Friends system
- 📝 Posts
- 💭 Comments and likes
- 🟢 Online status tracking
- 🔔 Notifications

## Tech Stack

**Frontend:** React, TypeScript, SignalR, CSS Modules
**Backend:** ASP.NET Core, Entity Framework Core, MySQL, SignalR, JWT

## Quick Start

**Requirements:** .NET 7.0+, Node.js 16+, MySQL 8.0+

1. Create a MySQL database and set the connection string in `backend/appsettings.json`.
2. Start the backend:
```bash
   cd backend
   dotnet restore
   dotnet run
```
3. Start the frontend:
```bash
   cd frontend
   npm install
   npm start
```
